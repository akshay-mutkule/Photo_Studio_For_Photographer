# 📸 Vinayak Sable Photography & Client Portal

A highly polished, full-stack photography portfolio, booking engine, and interactive client proofing platform designed for modern professional photographers. Built with **React 18**, **TypeScript**, **Tailwind CSS**, and **Express**, with persistent dual-layered storage supporting both **local JSON** and **Google Firebase Firestore**.

---

## ✨ Features

### 🌟 Client-Facing Portfolio & Site
- **Dynamic Portfolio Grid:** View high-resolution curated shots organized smoothly by categories (*Weddings, Pre-Wedding, Engagement, Portraits, Family, Maternity, Fashion, Wildlife, Commercial*).
- **Interactive Before/After Slider:** Elegant interactive sliding element showcasing premium professional retouching capabilities.
- **Sensory Storytelling Showcase:** Curated previews of major galleries with seamless navigation.
- **Full Booking & Consultation Platform:** Rich booking engine with built-in validation, immediate booking log creation, and inquiry confirmation.
- **Photography Blog:** Highly readable, responsive editorial section detailing styling guides, natural lighting workshops, and Maharashtra photoshoot spots.

### 🔒 Secure Client Portal (Proofing & Retouching)
- **Passcode-Protected Galleries:** Client-specific portals secured by unique passcodes generated by the photographer.
- **Interactive Selection & Proofing:** Clients can favorite photos, like/dislike, or mark individual high-resolution pictures for requested custom retouching.
- **Direct Proof Downloads:** Downloadable ZIP/individual items directly through the UI (photographer can enable/disable this feature per gallery).
- **Real-time Client Notifications:** In-app toast messages and notification center highlighting retouching updates, delivery schedules, and confirmation items.

### 👑 Premium Admin Dashboard
- **Business Performance Analytics:** Interactive dashboard presenting total bookings, active galleries, global proofing interactions, and client-favorite ratios.
- **Booking Manager:** View, filter, and modify client photoshoots (Pending ➔ Confirmed ➔ Completed).
- **Gallery Constructor:** Create client proofing vaults, upload media, define security passcodes, and control download permissions.
- **🚀 AI Admin Copilot (Gemini-Powered):** Ask natural language questions like *"Who booked a shoot on July 25?"*, *"Summarize this week's activities"*, or *"Suggest a creative lighting plan for family portraits"* for instant smart updates and shoot consultation insights.

## 🛠️ Technology Stack

- **Frontend:** React 18, TypeScript, Tailwind CSS, Lucide Icons, Framer Motion
- **Backend:** Node.js, Express, tsx, Esbuild
- **Persistence (Dual-Layered Cache):**
  - **Durable Cloud:** Firebase Admin SDK (Firestore Database)
  - **Local Hot Standby / Backup:** Auto-synced `db.json` cache (serves as zero-dependency standalone fallback)
- **AI Engine:** Google GenAI SDK (`@google/genai` targeting `gemini-2.5-flash`)
- **Asset Delivery:** Fast Unsplash CDN references with graceful fallback parameters

## 🚀 Getting Started

### 📦 Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18 or higher) and `npm` or `yarn` installed.

### 🔧 Environment Setup
Copy the example environment file:
```bash
cp .env.example .env
```

Open `.env` and fill in your custom configurations:
```env
# Google Gemini API Key for Admin Copilot
GEMINI_API_KEY=your_gemini_api_key_here

# Cloudinary Storage Configuration (Optional, falls back to local data if blank)
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

# Render or External Cloud Hosting Options
RENDER=true
FIREBASE_SERVICE_ACCOUNT={"type":"service_account","project_id":"..."}
```

### 💻 Local Run
1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Start the full-stack development workspace:**
   ```bash
   npm run dev
   ```
   *The Express server boots on `http://localhost:3000` and automatically mounts the Vite React application.*

## 📦 Build & Production Deployment

To package the application into a highly optimized, standalone production bundle:

### 1. Build Compilation
```bash
npm run build
```
This script triggers:
- `vite build` to bundle static asset paths into `dist/`
- `esbuild` compiler to bundle the Express backend down to `dist/server.cjs`

### 2. Standalone Start
```bash
npm run start
```
*The app is fully self-contained in `dist/` and ready for robust Docker container ingress or cloud hosting services.*

## ☁️ Deployment Guides

### 🚀 Deploying to Render
This project is pre-configured to run flawlessly on [Render.com](https://render.com) as a **Web Service**.

1. **Connect your GitHub Repository** to Render.
2. Configure the following build settings:
   - **Runtime:** `Node`
   - **Build Command:** `npm run build` (or `yarn install; yarn build`)
   - **Start Command:** `npm start` (or `yarn start`)
3. **Add Environment Variables:**
   - Set `RENDER=true` (this prevents Google Auth lookup crashes and forces Firestore fallback settings if credentials aren't initialized yet).
   - Add `GEMINI_API_KEY` for smart AI Copilot functionality.
   - *(Optional)* Provide `FIREBASE_SERVICE_ACCOUNT` with your Firebase Service Account JSON string to synchronize your local database with Cloud Firestore.
